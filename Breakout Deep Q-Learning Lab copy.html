Q-Learning vs Deep Q-Learning

Q-LearningDeep Q-Learning
Stores one number per (state, action) in a table.A neural network guesses Q-values from the state numbers.
Fine for a tiny maze with 50 squares.Needed here: ball position and speed are continuous, so there are endless possible states.
Cannot guess for states it never visited.Generalises: similar states give similar Q-values.
Q(s,a) = “how much total future reward do I expect if I do action a now, then play well?” Target: y = r + γ · max Q′(s′, a′). The network is nudged so its guess moves toward y.

🤔 Think about it

Why does the AI perform poorly at the beginning?Its network weights are random, so its Q-values mean nothing, and ε is high so it mostly moves randomly. Deeper: replay memory is also nearly empty, so there is little to learn from. With random weights the three Q-values are almost identical, so the greedy choice is basically arbitrary. Training only starts once memory holds at least 64 experiences.
How does the AI learn to follow the ball?When the paddle meets the ball it earns +0.1, and not missing avoids −2. Through the Bellman target those rewards flow backwards to earlier states, so “ball is right of paddle → go RIGHT” gets a higher Q-value. Watch the input “ball−paddle” light up the network.
Deeper: the network is never told the rule “follow the ball”. It only gets numbers and rewards. Following the ball is the pattern that happens to earn the most reward, so gradient descent discovers it. Watch the Q-value of LEFT vs RIGHT flip as the ball crosses the paddle’s centre.
What happens when exploration (ε) is set to zero?The AI only repeats what it currently believes. At the very start it believes nothing useful, so it may get stuck doing one move. Exploration lets it discover better actions.
Deeper: try it. Train 100 episodes, then drag ε to 0 and press Watch & learn. Compare with a fresh Reset Training at ε = 0. A trained network still plays well, an untrained one does not. This is the exploration–exploitation trade-off.
Why does the AI still make mistakes after training?The network is only an approximation, training is noisy, and some ball angles are rarely seen. During training it also keeps exploring randomly; use “Test AI” to see its greedy play.
Deeper: Q-values are estimates of the future, learned from limited data. Two nearly identical states can get slightly different Q-values, and a small error can flip which action looks best.
What happens if the reward system changes?The AI chases whatever you reward. If bounces pay more than bricks, it may just keep the ball alive. If losing a life costs nothing, it stops caring about misses.
Deeper: this is called reward shaping. The AI is not learning “play Breakout well”, it is learning “maximise this exact score”. Designing rewards that match what you really want is a major challenge in reinforcement learning.
How is Deep Q-Learning different from ordinary Q-Learning?See the table above: a neural network replaces the Q-table, plus tricks like replay memory and a target network keep training stable.
Deeper: with a table you update one cell. With a network, one update changes the weights for every state at once, which can make learning wobble. That is why the tricks below exist.
Why use a replay memory?Consecutive game frames are almost identical, and learning from them in order makes the network forget older situations. Sampling random old experiences mixes easy and hard moments, like shuffling flash cards. Deeper: it also lets each experience be reused many times, and it is why your own Round 1 experiences can teach the AI.
Why a separate target network?The target y = r + γ·max Q′ uses the network’s own guesses. If that same network is changing every step, the target keeps moving, like chasing your own shadow. A frozen copy, updated every N steps, holds the target still for a while. Deeper: try a target update of 100 vs 2000 and compare how smooth the loss chart looks.
